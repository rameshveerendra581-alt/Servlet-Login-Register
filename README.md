# Servlet Login & Registration System (Session-Based)

A Java Servlet-based web application implementing **user registration, login, logout, and session-based authentication** using JDBC and MySQL.

This project is built to strengthen **core servlet concepts** before moving to **Spring / Spring Boot**.

---

## 🚀 Features

- User Registration
- User Login (Email & Password)
- Session-based Authentication
- Protected Dashboard
- Logout (Session Invalidation)
- Responsive UI using HTML & CSS
- MySQL Database Integration

---

## 🛠 Tech Stack

- Java (JDK 17)
- Java Servlets
- JDBC
- Apache Tomcat 9
- MySQL
- HTML5, CSS3
- Eclipse IDE
- Git & GitHub
